Siftwell, portable version (no install)
=======================================

HOW TO RUN
  1. Unzip this ZIP anywhere you like: a folder in Documents, a USB stick, Dropbox.
     (Right-click the ZIP and choose "Extract all"; don't run it from inside the ZIP.)
  2. Open the Siftwell folder and double-click Siftwell.exe.
  3. Follow the page that opens. The first time, Siftwell makes a folder called
     "data" next to Siftwell.exe. Your profiles, resumes, ratings and settings live
     there.

The folder must be one you can write to (Documents, your Desktop, a USB stick). If
Siftwell says it can't save its data, move the Siftwell folder to Documents and
open it again.

WHAT IT DOES NOT DO
  By default nothing is installed and nothing is written outside this folder. "Start
  Siftwell when I sign in" and "Even when Siftwell is closed" (automatic updates) are
  off. You can still turn them on in Settings; Siftwell tells you first that this adds
  something to this computer, outside the Siftwell folder. Claude Code, if you use it,
  is installed on the computer as usual (it is not part of this folder).

DELETING THE FOLDER DELETES YOUR DATA
  Your data is inside the "data" folder, so deleting the Siftwell folder deletes your
  profiles, resumes and ratings. Keep a copy of the "data" folder somewhere safe, or
  use Settings > Backup & move.

UPDATING
  When a new version is out, Siftwell shows "Download the new portable version".
  1. Close Siftwell (close its window; if it keeps running for your phone, use Stop
     Siftwell from the tray icon).
  2. Unzip the new ZIP over your old Siftwell folder and choose "Replace the files".
     Or unzip it somewhere new and copy your old "data" folder into the new Siftwell
     folder.
  3. Double-click Siftwell.exe again.

MOVING TO ANOTHER COMPUTER OR DRIVE
  Close Siftwell, then move or copy the whole Siftwell folder (the data goes with it).
  The drive letter can change (a USB stick on E: or F:); that is fine. On a new computer:
  - your phone link changes (the computer has a different address): open Settings >
    Get started to see the new link;
  - Claude Code sign-in is per computer: use Settings > Get started to install it and
    sign in.

PORTABLE AND INSTALLED
  With Siftwell closed on both sides, either:
  - Settings > Backup & move: export on one, import on the other; or
  - copy the contents of %APPDATA%\JobBoard into the portable "data" folder (or the
    other way round).

TRYING A NEW VERSION NEXT TO YOUR MAIN COPY
  Unzip the portable version into a test folder and, if you like, copy your data folder
  into its "data" folder first. It runs on its own port (the window title says "test
  copy, port ...") and never touches your main copy.
